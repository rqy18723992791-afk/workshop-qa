# 故障案例卡——模具保护报警（A-402）

## 一、故障现象

换模后试生产，合模运行至低压保护段时机器报警 **A-402 模具保护异常**并停止合模，复位后可再次合模但仍在同一位置报警。目视模具型腔未见明显产品残留。

## 二、可能原因（按发生概率排序）

1. 型腔或分型面有残料、异物、顶针未完全退回。
2. 低压保护参数被误改：保护位置过小、保护压力过低、保护时间过短。
3. 模具保护接近开关/电子尺位置偏移、松动或信号漂移。
4. 模具导柱、导套缺油或拉伤，合模阻力增大。
5. 模具安装偏斜、模板平行度超差。
6. 合模位置尺（电子尺）漂移或损坏（概率较低）。

## 三、排查步骤

1. **查模具内部**：手动开模到底，断电后用手电筒检查型腔、分型面、顶针板，清除残料、料屑和异物；确认顶针全部退回。
2. **核对保护参数**：低压保护位置 **2～5 mm**、保护压力 **2～4 MPa**、保护时间 **1～2 s**。与工艺卡核对，确认是否被误改小或关闭。
3. **查保护开关**：检查模具保护接近开关固定是否松动，感应距离是否在 2～4 mm，清理感应面油污。
4. **查导柱导套**：清理并润滑导柱、导套，手动合模至保护位置，感受有无卡滞；拉伤严重时修模。
5. **查模具安装**：检查压板螺栓是否紧固、模具是否偏斜，必要时重新装模并测量模板平行度。
6. **查电子尺**：观察合模位置显示是否连续、无跳变；跳变或归零异常时校准或更换电子尺。

## 四、本次处置结果

- 检查发现分型面排气槽内嵌有一小片 ABS 残料，顶针 3 号位退回慢 0.5 s。
- 清除残料，清理并润滑顶针板导柱，复位开关重新调整。
- 恢复低压保护参数为位置 3 mm、压力 3 MPa、时间 1.5 s，A4 纸测试 3 次均有效。
- 试模 20 模无报警，交付生产。

## 五、预防措施

1. 换模后必须做 A4 纸低压保护测试，合格后方可自动运行。
2. 每班点检模具保护功能，严禁短接、屏蔽保护开关。
3. 周保养清理模具分型面、排气槽，润滑导柱导套。
4. 保护参数纳入工艺卡管理，修改需工艺员确认。

## 六、安全提示

- 严禁通过调大保护压力、缩短保护时间或短接开关的方式"消除"报警，这会使模具保护失效，可能造成模具损坏和人身伤害。
- 检查模具必须断电、停机、待模具冷却，严禁手伸入分型面。
- 合模区域有人作业时，必须关闭安全门并挂牌警示。
