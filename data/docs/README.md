# 示例知识库文档

围绕**注塑机**的自编示例文档（12–15 份，Markdown），随代码一起交付。

## 规范

- 每份文档文首带元数据：文档名、类别、版本、日期
- 内容像真实工厂文档：有具体数值、步骤编号、注意事项
- 数值使用行业常识范围内的合理值，不得抄网上现成手册原文
- 类别构成：
  - 设备操作手册节选 ×3（开机/停机流程、参数设定、安全操作）
  - 点检标准 ×3（日常点检表、周保、月保）
  - 故障案例卡 ×5（温度异常、顶出故障、液压异常、模具保护报警、产品缺陷如飞边/缩水）
  - 安全规程 ×2（锁模安全、应急处理）
  - 工艺参数参考 ×2（常用材料温度对照、注射参数说明）
