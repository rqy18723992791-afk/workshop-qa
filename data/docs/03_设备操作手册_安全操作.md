# 注塑机安全操作规程

## 一、个人防护

1. 进入车间必须穿工作服、防砸安全鞋，长发盘入工作帽内。
2. 接触高温料筒、热流道、刚脱模产品时必须佩戴耐高温手套。
3. 清理料筒、喷嘴时佩戴防护面罩，防止高温熔体喷溅伤人。
4. 禁止佩戴围巾、领带、手链等易被运动部件卷入的饰物。

## 二、开机前安全确认

1. 检查前安全门、后安全门、急停按钮、安全踏板是否有效，任一失效禁止开机。
2. 检查模具安装是否牢固，压板螺栓有无松动，模具区域有无异物。
3. 确认设备接地良好，电缆无破损，电箱门关闭。
4. 确认冷却水、压缩空气管路连接可靠，无渗漏。

## 三、运行中安全要求

1. **严禁将手、头或身体任何部位伸入模具闭合区域**，取件必须使用工具或机械手。
2. 机器运行时安全门必须关闭，严禁拆除、短接或屏蔽安全门限位开关。
3. 不得在机器运行时攀爬、跨越机台或倚靠安全门。
4. 调整模具、顶针、喷嘴时必须先切换到手动模式并停止油泵。
5. 两人协同作业时，必须约定一人操作、一人监护，开机前相互确认。

## 四、换模与调模安全

1. 换模前切断料筒加热和油泵电源，挂"正在换模"警示牌。
2. 使用吊车吊装模具时，确认吊环拧紧、钢丝绳无断股，模具下方严禁站人。
3. 调模时使用点动，严禁连续快速合模；调模完成后重新测试低压保护。
4. 换模结束后清理工具、螺栓，确认模具区域无遗留物再试机。

## 五、清理与保养安全

1. 清理料筒必须使用专用清料杆和铜铲，禁止用铁棒、铁锤敲击料筒。
2. 清理喷嘴时站在喷嘴侧面，避免正对喷嘴方向，防止熔体喷出。
3. 擦拭机器时禁止用湿布接触电气部件；清洁剂不得喷洒到电箱、电机。
4. 保养时执行**挂牌上锁**：切断总电源，挂"禁止合闸"牌，钥匙由保养人保管。

## 六、电气安全

1. 电箱内部检查、接线必须由持证电工操作，操作前验电、放电。
2. 禁止私拉乱接临时电源，禁止用铜丝代替保险丝。
3. 发现电缆发热、焦糊味、打火，立即断电并报修。

## 七、交接班与异常报告

1. 交接班时共同检查安全装置状态，并在《交接班记录》签字。
2. 发生未遂事故、安全装置失效、设备异常，必须立即报告班组长，不得隐瞒。
3. 发生人身伤害立即按《注塑车间应急处理规程》处置并上报。

## 八、禁止行为清单

- 禁止拆除或短接安全门限位、急停按钮、模具保护装置。
- 禁止在自动运行状态下打开安全门取件。
- 禁止酒后、疲劳或服药后操作设备。
- 禁止非持证人员独立操作注塑机。
- 禁止在设备运行时进行维修、清理、调整作业。
