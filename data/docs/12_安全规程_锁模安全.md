# 注塑机锁模区域安全规程

## 一、风险说明

锁模机构合模力最大可达 1600 kN。人员肢体进入模具闭合区域时，即使低压保护正常，也可能因保护失效、参数被改、开关短接而造成挤压、切断等严重伤害。锁模区域是本车间最高风险区域，必须严格执行本规程。

## 二、安全防护装置要求

1. 前安全门、后安全门必须完好，透明视窗无裂纹，门锁与限位开关动作可靠。
2. 安全门打开时，合模动作必须立即停止；关闭安全门后才能继续合模。
3. 急停按钮安装在操作位和机台后侧，按下后油泵立即停止。
4. 模具低压保护必须每班测试，位置 2～5 mm、压力 2～4 MPa、时间 1～2 s。
5. 机械手/取出机与注塑机联锁有效，机械手未退出时禁止合模。

## 三、低压保护测试方法（每班开机前）

1. 机器切手动模式，模具处于打开状态。
2. 在分型面之间放置一张 A4 纸（或专用测试片）。
3. 执行合模，模具运行至低压保护段应停止并报警。
4. 抽出 A4 纸，确认纸张无明显压痕、可轻松抽出。
5. 连续测试 3 次均有效，记录在《设备日常点检表》；任一次失效禁止开机。

## 四、禁止行为

- 严禁拆除、短接、屏蔽安全门限位开关、急停按钮、模具保护开关。
- 严禁在自动运行状态下打开安全门伸手取件。
- 严禁两人同时操作同一台机器而不沟通。
- 严禁在合模区域放置工具、抹布、料袋等物品。
- 严禁为提升节拍缩短低压保护时间或提高保护压力。
- 严禁非持证人员操作注塑机。

## 五、调模与换模作业

1. 换模前切断料筒加热与油泵电源，挂"正在换模"警示牌。
2. 吊装模具时模具下方严禁站人，确认吊环、钢丝绳完好。
3. 调模使用点动，严禁连续快速合模；调模时手不得扶在分型面上。
4. 换模完成后重新测试低压保护，清理工具和螺栓，确认无误后试机。

## 六、维修作业

1. 进入模具区域维修必须执行**挂牌上锁**：切断总电源、关闭油泵、挂"禁止合闸"牌，钥匙由维修人保管。
2. 涉及液压系统维修必须先泄压，确认压力表归零。
3. 维修完成后由维修人和操作工共同确认安全装置有效，签字后交付生产。

## 七、异常处置

1. 发现安全门限位失灵、低压保护失效，立即停机、挂"禁止操作"牌并报告班组长。
2. 发生人员夹伤，立即按下急停，按《注塑车间应急处理规程》处置，禁止强行拉拽伤者。
3. 任何安全装置异常不得带病运行，修复前设备不得投入使用。

## 八、培训与考核

新员工上岗前必须完成锁模安全专项培训并考核合格；在岗人员每半年复训一次，培训记录归档。
