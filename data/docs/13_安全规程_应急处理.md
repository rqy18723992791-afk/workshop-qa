# 注塑车间应急处理规程

## 一、应急电话与报告流程

- 医疗急救：120；火警：119；厂内应急值班：6119；车间主任：内线 6201。
- 任何事故第一时间按下急停、保护现场，并报告班组长和车间主任；人身伤害同时拨打 120。
- 事故处理后 24 小时内提交书面报告，不得隐瞒、迟报。

## 二、人员夹伤/挤压

1. 立即按下最近处的急停按钮，停止设备所有动作。
2. **禁止强行拉拽伤者**，防止二次伤害；需要退模时由维修人员手动泄压、点动退模。
3. 拨打 120，同时进行止血、包扎等现场急救；疑似骨折时固定伤肢，不要随意搬动。
4. 保护现场，拍照记录设备状态、安全门位置、保护参数，配合事故调查。
5. 事故设备挂牌停用，未经设备科和安环科确认不得重启。

## 三、高温熔体烫伤

1. 立即脱离热源，用流动冷水冲洗烫伤部位 15～20 分钟，不要涂抹牙膏、酱油等。
2. 衣物与皮肤粘连时不要强行撕脱，剪开周围衣物。
3. 大面积烫伤、面部烫伤立即拨打 120。
4. 清理喷溅到地面的高温熔体，待冷却后铲除，防止人员滑倒烫伤。

## 四、触电

1. 立即切断电源或用绝缘物挑开电线，**严禁徒手接触触电者**。
2. 触电者呼吸心跳停止时，立即进行心肺复苏，持续到急救人员到达。
3. 拨打 120 并报告厂内应急值班。
4. 电气设备故障由持证电工排查，确认绝缘合格后方可送电。

## 五、液压油泄漏

1. 立即停机、切断电源，关闭相关阀门，防止继续泄漏。
2. 用吸油棉、沙土围堵收集，禁止用水冲洗，防止油污进入下水道。
3. 泄漏区域设置警示标识，清理干净后方可通行。
4. 大量泄漏或泄漏进入雨排系统，立即报告安环科。
5. 废油、吸油棉按危险废物分类收集，交由有资质单位处理。

## 六、火灾

1. 立即切断设备总电源，按下消防报警按钮，拨打 119。
2. 电气火灾使用二氧化碳或干粉灭火器，**严禁用水扑救**。
3. 液压油着火使用干粉、泡沫灭火器，隔离周边可燃物。
4. 火势无法控制时，按疏散路线撤离，清点人数，禁止返回取物。
5. 消防通道、灭火器、消火栓保持畅通，每月检查一次。

## 七、机械手/行车异常

1. 机械手失控时立即按下急停，人员撤离到安全区域。
2. 行车吊物坠落风险时，疏散下方人员，禁止用手扶正吊物。
3. 由持证人员处理，禁止私自攀爬设备。

## 八、应急演练与培训

1. 每季度组织一次消防与人身伤害应急演练，记录演练情况。
2. 新员工入职必须学习本规程并签字确认。
3. 应急物资（急救箱、灭火器、吸油棉、洗眼器）每月检查，缺失立即补充。
